# Branding

The DeepEyeMusicPro mark combines an eye silhouette, audio waveform, and cyan tech accent. The adaptive launcher icon is vector-based so builders can replace it with production artwork without changing manifest wiring.

Store icon guidance:

- 512×512 PNG
- Dark graphite background
- Cyan/white eye-waveform fusion mark
- No text in the icon
- Keep the mark inside the safe zone for adaptive icon masks
