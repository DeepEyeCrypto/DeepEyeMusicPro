# UI Guidelines

DeepEyeMusicPro uses a premium dark audio-first visual system:

- Deep black and graphite base surfaces
- Charcoal elevated cards with cyan-blue highlights
- Artwork-first player presentation
- Clean hierarchy, large touch targets, and restrained glow
- Bottom sheets for DSP, queue, and now-playing detail
- Empty, loading, and error states that explain recovery paths

Avoid generic demo UI. Prefer fewer controls per surface, richer spacing, and direct audio actions.
